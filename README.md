# VVTV Platform (Phase 0 Scaffold)
This directory contains the Phase 0 foundation scaffold for the VVTV / Voulezvous platform.
Key scripts:
- `npm run validate:config`
- `npm run validate:contracts`
- `npm run generate:types`
- `npm run check:boundaries`
- `npm run evidence:phase0`
- `npm run ci:phase0`
